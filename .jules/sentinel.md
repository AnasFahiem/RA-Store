## 2024-05-18 - [Missing Authorization Checks in bundleActions.ts]
**Vulnerability:** Several sensitive functions in `lib/actions/bundleActions.ts` (`createBundle`, `getPromoCodes`, and `getPromoCodeById`) lacked role-based authorization checks before utilizing a service-role client (`createAdminClient()`). This allowed unauthenticated or unprivileged users to bypass Row Level Security (RLS) and perform actions like creating bundles or viewing sensitive promo code details (IDOR/Information Disclosure).
**Learning:** Next.js Server Actions are public API endpoints. When using a service-role client (`createAdminClient`) that bypasses RLS, explicit role-based authorization must be enforced directly within the server action itself, as it cannot rely on database-level security policies.
**Prevention:** Always verify the user's role (e.g., using `verifyAdmin()`) at the beginning of any Next.js Server Action that interacts with sensitive data or uses `createAdminClient()`. Ensure uniform authorization logic by using shared helper functions rather than duplicating checks.

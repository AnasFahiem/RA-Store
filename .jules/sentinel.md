## 2025-02-28 - [Fix Information Disclosure in Promo Codes]
**Vulnerability:** The server actions `getPromoCodes` and `getPromoCodeById` in `lib/actions/bundleActions.ts` were using the service-role Supabase client (`createAdminClient()`) without any explicit role checks. This allowed unauthenticated or non-admin users to potentially access sensitive promo code data (e.g., active promo codes, discount values) by invoking these public server actions.
**Learning:** Using a service-role client bypasses Row Level Security (RLS) entirely. When such clients are used in Next.js Server Actions, which are inherently public API endpoints, explicit authorization logic (e.g., verifying user session and role) must be implemented within the action itself to prevent unauthorized data exposure.
**Prevention:** Always verify the user's session and role using `getSession()` before executing database queries with a service-role client in server actions, especially for endpoints that return sensitive or admin-only data.

## 2024-07-25 - Predictable JWT Key Generation
**Vulnerability:** The application initializes the JWT signing key using `new TextEncoder().encode(process.env.JWT_SECRET)`. If the `JWT_SECRET` environment variable is not defined, Node.js evaluates it to `undefined`, resulting in a zero-length array (Node v22+) or the string 'undefined' (older versions). This predictability allows an attacker to trivially forge valid JWTs, completely bypassing authentication.
**Learning:** Functions that consume environment variables for cryptographic operations must validate the presence of these variables *before* use. A fail-open or silent failure in secret initialization leads to critical vulnerabilities where the "secret" becomes publicly known or predictable.
**Prevention:** Implement strict presence and type validation for all critical environment variables at startup or immediately before use. Throw an explicit, descriptive error if the variable is missing to prevent the application from starting in an insecure state.

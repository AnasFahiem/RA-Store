## 2026-06-16 - Prevent Privilege Escalation in Bundle Creation
**Vulnerability:** A critical price manipulation and privilege escalation vulnerability was discovered in `createBundle` (`lib/actions/bundleActions.ts`). The `createBundle` endpoint parses client-provided data, and any user could theoretically send malicious form data setting `type: 'admin_fixed'` and providing an arbitrary low `priceOverride` for the bundle.
**Learning:** The vulnerability existed because Server Actions that expose database insertions using `createAdminClient()` (which bypasses RLS) trusted the input parsed from the `BundleSchema` directly without verifying that the requesting user actually possessed the required privileges (e.g. `admin` or `owner` role) to set administrative fields such as `type` and `priceOverride`.
**Prevention:** Always enforce role-based authorization explicitly inside the Server Action before performing operations using a service-role client. Strip or override privileged fields from user input based on the user's role before trusting it.

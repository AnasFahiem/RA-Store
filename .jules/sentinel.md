## 2025-02-23 - Prevent Price Manipulation in Order Checkout
**Vulnerability:** In `lib/actions/orderActions.ts`, the `placeOrder` server action blindly trusted the client-provided `item.price` values from the checkout form data. An attacker could manipulate the request payload, change prices to `0` or any arbitrary amount, and execute a successful checkout without paying the proper value. This falls under Insecure Direct Object Reference (IDOR) and parameter manipulation vulnerabilities.
**Learning:** Client-provided calculations and values (like cart totals or item prices) should never be trusted as the authoritative source of truth in backend processes, particularly when those numbers dictate financial transactions.
**Prevention:** Always recalculate prices server-side by fetching authoritative data directly from the secure database (e.g., retrieving `base_price` from `products` and `price_override` from `bundles` based on `product_id`). Apply bundle aggregation logic explicitly on the backend before completing the transaction.

## 2024-05-24 - [Broken Access Control] Missing Authorization Checks in Server Actions
**Vulnerability:** The Next.js Server Actions `getPromoCodes` and `getPromoCodeById` in `lib/actions/bundleActions.ts` utilized `createAdminClient()` (which bypasses Row Level Security) but failed to enforce explicit role checks. This allowed unauthenticated or unauthorized users to fetch sensitive promotional code data, including active codes and discounts.
**Learning:** Next.js Server Actions are exposed as public API endpoints. When utilizing a service-role Supabase client (`createAdminClient`) within these actions, RLS is bypassed. Without explicit authorization checks (e.g., verifying user roles), these endpoints become vulnerable to Broken Access Control.
**Prevention:** Always explicitly verify user roles and authentication state using a helper like `verifyAdmin()` at the beginning of any Server Action that accesses or modifies sensitive data, especially when using `createAdminClient()`.

## 2024-07-02 - [JWT Secret Coercion Vulnerability]
**Vulnerability:** The codebase was directly passing `process.env.JWT_SECRET` to `new TextEncoder().encode()` without validating its presence. If `JWT_SECRET` is unset, `process.env.JWT_SECRET` is `undefined`. `TextEncoder().encode()` coerces `undefined` into the string `"undefined"`, generating a predictable 9-byte array `[117,110,100,101,102,105,110,101,100]`. This allows an attacker to forge valid JWTs using the known key `"undefined"`, leading to a complete authentication bypass.
**Learning:** Node.js APIs, such as `TextEncoder`, often perform implicit type coercion. When dealing with security-critical secrets like JWT keys, we must explicitly check for missing values to prevent them from being silently converted into predictable strings.
**Prevention:** Always explicitly validate that critical environment variables (like `JWT_SECRET`) are defined and not empty before using them. Throw an error on initialization if they are missing to ensure the application fails securely (fail-closed).

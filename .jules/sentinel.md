## 2024-06-09 - Missing JWT_SECRET Validation Allows JWT Forgery
**Vulnerability:** The application was directly calling `new TextEncoder().encode(process.env.JWT_SECRET)` without validating that `process.env.JWT_SECRET` was set. In JavaScript, `encode(undefined)` evaluates to a valid 9-byte array `[117, 110, 100, 101, 102, 105, 110, 101, 100]` which corresponds to the string `'undefined'`. This created a critical vulnerability where an attacker could forge valid JWT tokens because the secret key was known and predictable when the environment variable was missing.
**Learning:** `new TextEncoder().encode()` does not throw an error or create an empty key when passed `undefined`. It implicitly converts `undefined` to the string `'undefined'` before encoding. This behavior can lead to severe security flaws in cryptographic operations if inputs are not strictly validated.
**Prevention:** Always validate critical environment variables, especially secrets and keys used for cryptographic operations, at startup or before their first use. Explicit checks like `if (!process.env.JWT_SECRET) throw new Error(...)` ensure the application fails securely rather than running with a weak or predictable configuration.

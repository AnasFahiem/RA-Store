## 2024-06-20 - Open Redirect in Auth Callback
**Vulnerability:** The application was vulnerable to Open Redirect attacks in the Next.js auth callback (`app/auth/callback/route.ts`). It blindly redirected users to URLs constructed from the unverified `X-Forwarded-Host` HTTP header, which can be easily spoofed by attackers to redirect users to malicious domains after login.
**Learning:** In environments behind load balancers or proxies, `X-Forwarded-Host` is useful but cannot be trusted blindly, especially for security-critical operations like redirects after authentication. The original fix simply used it if present, allowing anyone to control the redirect destination by forging this header.
**Prevention:** Always validate `X-Forwarded-Host` against a known, trusted list of allowed hosts or a trusted environment variable like `NEXT_PUBLIC_SITE_URL` before using it in redirects. If it doesn't match the expected host, fall back to the original request origin or a safe default.
